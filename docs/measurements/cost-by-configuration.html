委譲構成コスト早見表

親モデル・effort・委譲・advisor の組み合わせごとの費用。単価は litellm の model_cost、 トークンは手元の実セッションと DeepSWE ベンチの実測値から取っている。 推計を含む行には * を付けた。

ultra は「max より上」ではない。 ultra は努力度の最上位ではなく V2 の自発委譲モードの指定で、ワイヤ上に送られる effort は別に解決される。 Astra はカタログに multi_agent_reasoning_effort = "xhigh" を持つため、ultra を選ぶと実際に送られるのは xhigh。推論の深さだけなら max より一段下になる。

02effort 別の実測

~/.codex と ~/.hsin の全ルートスレッドから、モデル・effort 別に中央値を取った。 子エージェントは含まない。すべて実測。

effort とセッションの長さが交絡している。 effort ごとに実行したタスクが違うので、難易度を揃えていない。 実際、高い effort のセッションは長くもある（ツール呼び出しが low 26回 → max 48回）。 「難しいから高い effort を選んだ」のか「effort を上げたから丁寧に働いた」のかは、このデータでは区別できない。 そこで 1 要求あたりの額も併記し、要求数 33 本（low の中央値）に揃えた列を置いた。 そちらが effort だけを取り出した値になる。

04構成別の総額

基準は Luna ultra（子も Luna）。advisor は Luna ultra を親とする場合のみ。 ultra の行は子のモデルで2通り並べた（Luna に固定した場合と、指定せず親と同じモデルを継いだ場合）。 $ / session は実績そのままで、02 の交絡（高い effort ほど長いセッションで使われている）を引き継ぐ。 実質単価 は親の要求 33 本ぶんの作業に揃えた額で、その交絡を除いてある。 * の行は子エージェント本数・advisor の入出力長・指摘後の追加作業量・Sol max の外挿のいずれかに仮定を含む。 この表の額はいずれも 02 の交絡を引き継いでいるので、「その構成を実際に使った場面込みの実績」として読むこと。 effort だけを比べたい場合は 02 の同一長換算を見る。

05委譲は効いたか

DeepSWE v1.1 の同一10タスクを、同じ Luna で effort と委譲の有無だけ変えて実測した結果。 失敗3件はいずれも「検証していないのに完了宣言」した型で、effort を上げても直らない性質だった。

差がついた3タスクはすべて委譲なし側が「あと少し」で落としたもの（f2p 136/137 など）。 ただし spawn 33回すべてで agent_type が省略され、子32本は全部 Luna だった。 上位モデルへ上がる経路はツール定義に存在していない。

06推計に含まれる仮定

  • 子エージェントは 3.2本 / タスク。Luna ultra の実測から取っており、Astra ultra の委譲実績は手元にない
  • Astra の子の出力は Luna 比 1.6倍と置いた（effort 表の xhigh / ultra 比から）
  • advisor の transcript は 60k トークン、出力は 3k トークン。advisor は Luna ultra を親とする場合のみ算出した
  • Sol の ultra はワイヤ上 max に解決されるが Sol max は未実測。Astra の max/medium 比（入力 1.60x・出力 2.96x）を Sol medium に当てて外挿した
  • Sol の子は Luna 比 1.4倍の出力、Astra の子は 1.6倍と置いた
  • advisor の指摘後にエージェントが追加で働く分は、親トークンの 25%
  • セッション単位なので内容の重さはばらつく。すべて中央値で比較している
  • effort ごとに実行したタスクが違い、難易度を揃えていない。02 の同一長換算と 04 の実質単価が、その影響を除いた値
  • 実質単価は「親が要求を 33 本こなす作業」に揃えた額。子の本数は DeepSWE 実測の比（親 194 要求に対し子 3.2 本 × 40 要求 = 親 1 要求あたり 0.66 子要求）で按分し、advisor は 1 回とした
  • DeepSWE の行だけタスク単位で、他はセッション単位。単位が違うので直接は比べられない
単価は litellm model_cost の base tier。トークンは ~/.codex / ~/.hsin の rollout と hsincli-bench の DeepSWE 実行から集計。* は推計を含む行。
