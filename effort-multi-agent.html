effort と multi_agent_v2 の違い

2つは別の設定軸です。Max / Ultra は推論レベル、 multi_agent_v2 は委譲の仕組みを決めます。

推論の深さ ＋ エージェント委譲の方式

1. Max と Ultra

Ultra は単純な「Max より大きい数値」ではなく、V2 の既定の委譲モードも切り替える特別な選択です。

Max
Max通常の最大推論レベル
→
モデル設定を解決通常は API に max 相当を送る
→
V2: 明示要求中心必要な時に委譲を依頼する

V2 が有効な場合の既定値です。V2 でなければ、V2 専用の委譲モードは入りません。

Ultra
UltraHsinCLI の拡張レベル
→
モデル設定を解決multi-agent 用設定 → max → 非 Ultra の順で縮退
→
V2: 積極的に委譲必要なら自律的にサブエージェントを使う

モデルが Ultra を API で受け付けるとは限りません。ワイヤ上の値と、V2 の委譲指示は別々に解決されます。

V2 なし Ultra

推論レベルの拡張として扱われます。V2 の自律委譲モードは有効になりません。

V2 あり Ultra

推論レベルに加えて、積極的な委譲（proactive）が既定になります。

2. multi_agent_v2 = true / false

true は V2 を明示的に選びます。false または未指定は、モデルカタログと他の設定から実行方式を決めます。

設定 features.
multi_agent_v2 委譲 API の世代を決める分岐
true → V2 を強制

V2 の collaboration ツールと、Ultra / Max に応じた委譲モードを使います。

false / 未指定 → 周辺設定を確認

agents.enabled、モデルカタログの multi_agent_version、従来の Collab 設定を順に見て、V2 / V1 / 無効を決めます。

設定 推論 委譲 覚え方
Max + false 最大レベル モデル・カタログ依存 既定の最大推論
Ultra + false モデルが非対応なら max 等へ縮退 V2 は強制しない Ultra を表示できても、V2 とは限らない
Max + true 最大レベル V2・明示要求中心 最大推論 ＋ V2
Ultra + true Ultra の解決規則に従う V2・積極的な委譲 Ultra の主な組み合わせ

3. Luna の具体例

Luna は bundled catalog では V1 で、Ultra を通常の対応レベルとして持ちません。

[features]
multi_agent_v2 = true

[model_reasoning_levels]
"gpt-5.6-luna" = ["ultra"]

Luna → Ultra → V2

UI には Ultra を追加できますが、モデル側の対応レベルが変わるわけではありません。 リクエストの推論値は通常 max 相当へ縮退し、multi_agent_v2 = true が V2 を選びます。 そのため、実際の組み合わせは「max 相当の推論 ＋ V2 の委譲」です。

モデルカタログや server 側の設定に独自の multi_agent_mode_hint_text がある場合は、その指示が優先されます。
